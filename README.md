# SafeMe · קבצי הפצה

מאגר זה מכיל **בינאריות בלבד** — מתקינים ועדכונים של סוכן SafeMe.
אין כאן קוד מקור.

## למה הוא ציבורי

הסוכן מאמת כל קובץ שהוא מוריד: סכום ביקורת SHA-256 וחתימה במפתח
ייעודי, נפרד ממפתח המדיניות ומכל מפתח אחר במערכת. האבטחה אינה
נשענת על כך שהקובץ סודי, ולכן אין סיבה להסתיר אותו — ויש סיבה טובה
שלא: רוחב פס חינם והורדות מהירות לכל הלקוחות.

## גרסאות ישנות

גרסאות קודמות נשארות זמינות כאן, כולל כאלה שהוחלפו.

**אין להתקין אותן.** הסוכן מסרב לגרסה נמוכה מזו שכבר רצה אצלו,
גם כשהיא חתומה כדין — שדרוג לאחור לגרסה עם פגם ידוע הוא דרך תקיפה,
והוא נראה בדיוק כמו עדכון תקין.

## התקנה

דרך האתר. ההורדה משם מקשרת את המחשב לחשבון שלך אוטומטית.
